⚡ HitPay Integration (TnG · FPX · Card · GrabPay)
Setup steps:
1. Create account at hitpayapp.com — no monthly fee, 1.9%/txn
2. Get verified (1-3 business days)
3. Go to Settings → API Keys → copy API Key + Salt
4. Dashboard → Payment Methods → enable TnG, FPX, Card
5. Dashboard → Developers → Webhooks → add: https://yourdomain.com/api/hitpay/webhook
6. Paste keys here, uncheck Sandbox, save
